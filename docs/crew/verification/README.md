# Verification Records

These records capture reproducible evidence for implemented Crew slices. A
verification record is not a new product decision and does not replace its
spikes, RED tests, approved plan, or current status.

Use one numbered record per delivered slice. State the real boundary exercised,
commands, observable results, environment limits, and cleanup.
